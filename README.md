# Estimativa da Altura de Árvores utilizando LiDAR e Modelagem 3D

Projeto desenvolvido em Python para estimar a altura de árvores a partir do processamento de nuvens de pontos tridimensionais obtidas por meio de dados LiDAR. O sistema apresenta a altura estimada diretamente no terminal e permite gerar uma visualização 3D interativa dos dados, facilitando a análise da estrutura da vegetação.

O projeto foi desenvolvido para apresentação na **Exposição de Cursos no shopping de Serra Talhada – PE**, demonstrando aplicações da programação, da computação e do sensoriamento remoto no monitoramento ambiental.

## Objetivos

- Estimar a altura de árvores utilizando dados LiDAR.
- Processar e analisar nuvens de pontos tridimensionais.
- Gerar visualizações 3D interativas da vegetação.
- Demonstrar aplicações da tecnologia no monitoramento ambiental.

## Tecnologias utilizadas

- **Python:** linguagem de programação utilizada no desenvolvimento.
- **LiDAR:** tecnologia de aquisição de dados tridimensionais.
- **Processamento de nuvens de pontos:** análise dos dados espaciais.
- **Visualização 3D interativa:** representação espacial dos dados processados.

## Funcionalidades

- Processamento de dados tridimensionais.
- Estimativa da altura das árvores.
- Exibição dos resultados diretamente no terminal da IDE.
- Geração de modelo 3D interativo para exploração visual dos dados.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/ManoelDavy/Estimativa-de-altura-de-arvore-por-meio-de-imagens-de-drone-com-sensor-LiDAR.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Estimativa-de-altura-de-arvore-por-meio-de-imagens-de-drone-com-sensor-LiDAR
   ```

3. Instale as dependências necessárias, conforme os módulos utilizados no projeto.

4. Execute o arquivo principal:

   ```bash
   python main.py
   ```

**Observação:** o nome do arquivo principal e as dependências devem ser conferidos na estrutura atual do repositório.

## Dependências

- **Python** — linguagem de programação utilizada no projeto.
- **NumPy** — processamento e operações numéricas com arrays.
- **Laspy** — leitura e processamento de arquivos de nuvens de pontos LiDAR (`.las` e `.laz`).
- **Plotly** — criação de visualizações 3D interativas.

## Aplicações

O projeto demonstra como dados LiDAR e ferramentas computacionais podem contribuir para:

- Monitoramento da vegetação.
- Estudos ambientais e florestais.
- Análise da estrutura tridimensional de árvores.
- Desenvolvimento de soluções tecnológicas para o sensoriamento remoto.
